# بوت الموظفين — بركات الكوثر

الموظف يكتب بكروب الموظفين على التليكرام طلبه بالعراقي، والبوت يقرأ شيت الأسعار من Google Sheets ويرجع النص جاهز.

```
الموظف: دزلي نص كروبات بيروت
البوت:  📄 بيروت بغداد · نسخة الزبون (بدون عمولة)
        ⭕️كروب بيروت من بغداد …
```

## شنو يسوي

- يفهم الطلب بالعراقي ويختار الشيت الصح. إذا الطلب يطابق أكثر من شيت (مثل "كروبات بيروت") يرجع نص لكل واحد، لحد 4.
- إذا الطلب مو واضح يسأل الموظف أي عرض يقصد.
- **نسختين:** النص يطلع للزبون بدون عمولة. إذا الموظف كتب "شركات" بطلبه يطلع نص الشركات ويا العمولة.
- يجاوب على سؤال محدد بسطرين: "شكد سعر الروشة 5 أيام من بغداد؟"
- يرد داخل كروب الموظفين فقط. أي محادثة ثانية ما يرد عليها.

## قواعد لازم تعرفها

| القاعدة | شلون تشتغل |
|---|---|
| العروض الفعالة | **الشيت المخفي = عرض قديم.** البوت يقرأ الشيتات الظاهرة فقط. حتى توقف عرض: كليك يمين على الشيت ← Hide sheet. |
| العملة | تنقرأ من تنسيق الخلية. إذا التنسيق بيه `$` فهو دولار. رقم 10,000 وفوق بدون رمز ينحسب دينار. |
| العمولة | أي خلية تذكر "عمولة" تنحذف من بيانات نسخة الزبون قبل ما توصل لـ Claude، وأي سطر بالناتج يذكرها ينحذف هم. |
| التحديث | البوت يعيد قراءة الشيت كل 10 دقايق. للتحديث الفوري: `/refresh`. |
| الخاتمة | أرقام الفروع والهاشتاك وجملة "الأسعار ممكن تتغير" تنضاف تلقائياً بآخر كل نص عرض. |

## التشغيل (5 خطوات)

### 1. الشيت على Google Sheets
1. ارفع ملف الإكسل على Google Drive وافتحه.
2. من القائمة: **File ← Save as Google Sheets** (مهم، حتى يصير شيت حقيقي مو ملف إكسل).
3. **Share ← Anyone with the link ← Viewer**.
4. انسخ معرف الشيت من الرابط: الجزء بين `/d/` و `/edit`.

> تنبيه: المشاركة بالرابط تعني أي شخص يوصله الرابط يشوف الأسعار والعمولات. إذا تريد الشيت يبقى خاص، شوف "الوضع الخاص" بالأسفل.

### 2. البوت من BotFather
1. بالتليكرام افتح `@BotFather` واكتب `/newbot` وخذ التوكن.
2. اكتب `/setprivacy` ← اختار البوت ← **Disable**. بدون هذي الخطوة البوت ما يشوف رسائل الكروب.
3. سوي كروب للموظفين وضيف البوت بيه. إذا البوت كان مضاف قبل خطوة 2، طلعه ورجعه.

### 3. الرفع على Render
1. ارفع الملفات (`bot.py` و `pricing.py` و `requirements.txt`) على مستودع GitHub.
2. بـ Render: **New ← Web Service** واختار المستودع.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. أضف المتغيرات:

| المتغير | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت |
| `ANTHROPIC_API_KEY` | مفتاح Claude API (نفس مال بوت خدمة العملاء أو مفتاح جديد) |
| `SHEET_ID` | معرف الشيت من الخطوة 1 |
| `ALLOWED_CHAT_IDS` | اتركه فارغ هسه |

### 4. ربط كروب الموظفين
1. بالكروب اكتب `/id`. البوت يرجعلك رقم يبدأ بـ `-100`.
2. حط الرقم بمتغير `ALLOWED_CHAT_IDS` على Render واحفظ. الخدمة تعيد التشغيل لوحدها.

### 5. التجربة
1. بالكروب: `/sheets` ← لازم تطلع قائمة العروض الفعالة.
2. اكتب: `دزلي نص كروبات بيروت`
3. اكتب: `نص اسطنبول للشركات` وتأكد العمولة تطلع بهذا فقط.

## أوامر الموظف

| الأمر | الوظيفة |
|---|---|
| أي رسالة عادية | طلب نص أو سؤال عن سعر |
| `/sheets` | قائمة العروض الفعالة |
| `/refresh` | إعادة قراءة الشيت هسه |
| `/id` | معرف المحادثة |
| `/help` | أمثلة |

## متغيرات اختيارية

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `CACHE_MINUTES` | `10` | كل كم دقيقة يعيد قراءة الشيت |
| `WRITER_MODEL` | `claude-sonnet-5` | الموديل اللي يكتب النص |
| `ROUTER_MODEL` | `claude-haiku-4-5-20251001` | الموديل اللي يفهم الطلب ويختار الشيت |
| `POST_FOOTER` | أرقام الفروع والهاشتاك | خاتمة كل نص |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | فارغ | للوضع الخاص |

## الوضع الخاص (بدون مشاركة بالرابط)

1. بـ Google Cloud Console سوي Service Account ونزّل مفتاحه بصيغة JSON.
2. شارك الشيت ويا إيميل الـ Service Account كـ Viewer، ورجّع المشاركة العامة لـ Restricted.
3. حط محتوى ملف الـ JSON كامل بمتغير `GOOGLE_SERVICE_ACCOUNT_JSON`.
