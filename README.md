# بوت الموظفين — بركات الكوثر (النسخة المجانية)

الموظف يكتب بكروب الموظفين على التليكرام اسم العرض، والبوت يقرأ شيت الأسعار من Google Sheets ويرجع النص جاهز.

**بدون ذكاء اصطناعي وبدون أي اشتراك:** البوت ينقل الأرقام من الشيت مثل ما هي ويرتبها بقالب ثابت. ما يحسب وما يخمن.

```
الموظف: دزلي نص كروبات بيروت
البوت:  لكيت 4 عروض. أي واحد تريد؟
        [بيروت بغداد] [بيروت نجف] [بيروت اور] [برنامج بيروت بدون طيران] [📚 الكل]

الموظف: بيروت نجف
البوت:  📄 بيروت نجف · نسخة الزبون (بدون عمولة)   [💼 نسخة الشركات]
        ⭕️ بيروت نجف
        🔹 Villa Queens — الحمرا (3⭐)
        ⬅️ 4 ايام / 3 ليالي | 580,000 د.ع | السنكل: 675,000 د.ع
        …
```

## شلون يطلب الموظف

| يكتب | البوت يسوي |
|---|---|
| اسم العرض: `بيروت نجف` ، `اسطنبول اور` ، `شمال ايران` | يرسل النص مباشرة |
| اسم عام: `بيروت` ، `تركيا` ، `فيزا` | يطلع أزرار بكل العروض المطابقة + زر **الكل** |
| اسم فندق أو منطقة: `الروشة` ، `بتايا` ، `صلالة` | يلكي العروض اللي بيها هذا الاسم |
| يضيف كلمة `شركات` أو `وكالات` | يرسل نسخة الشركات ويا العمولة |
| يضيف كلمة `مختصر` | يرسل النص بدون الملاحظات الطويلة |
| `/sheets` أو `شنو العروض` | كل العروض الفعالة كأزرار |

تحت عنوان كل نص أكو زرين: التبديل بين **نسخة الزبون / نسخة الشركات**، و**ويا الملاحظات / بدون الملاحظات**.
النص نفسه ينرسل برسالة لوحده بدون أزرار، حتى ينسخه الموظف أو يحوله للزبون نظيف.

السوالف العادية بالكروب ما يرد عليها البوت. يرد إذا الرسالة قصيرة وبيها اسم عرض، أو بيها كلمة طلب (نص، عرض، سعر، دزلي…).

**اللي ما يسويه:** ما يجاوب على سؤال محدد مثل "شكد سعر الروشة 5 أيام". يرسل نص العرض كامل والموظف يشوف السعر منه.

## قواعد الشيت

| القاعدة | شلون تشتغل |
|---|---|
| العروض الفعالة | **الشيت المخفي = عرض قديم.** البوت يقرأ الشيتات الظاهرة فقط. حتى توقف عرض: كليك يمين على الشيت ← Hide sheet. |
| اسم الشيت | هو اسم العرض اللي يكتبه الموظف وهو عنوان النص. سمّي الشيت باسم واضح. |
| صف العناوين | البوت يعرف العمود من عنوانه: `اسم الفندق` ، `الموقع` ، `تقييم الفندق` ، `عدد الايام` ، `المبيع / البيع / التسديد / الدبل / السعر` ، `السنكل` ، `الرضيع` ، `الطفل` ، `تاريخ السفر` ، `البرنامج` ، `الملاحظات`. عمود `صور` ينهمل. |
| الخلايا المدموجة | الفندق المدموج على أكثر من صف ينكتب مرة وحدة وتحته مدده. الخلية العريضة المدموجة تصير عنوان قسم (📍) أو ملاحظة (📌). |
| العملة | تنقرأ من تنسيق الخلية. إذا التنسيق بيه `$` فهو دولار. رقم 10,000 وفوق بدون رمز ينحسب دينار. رقم صغير بدون رمز تحت عمود سعر ينحسب دولار. |
| العمولة | أي ذكر لكلمة "عمولة" ينقص من نسخة الزبون، ويطلع بسطر 💼 بنسخة الشركات فقط. اكتب العمولة بخلية العنوان مثل ما هي هسه. |
| جدول ما ينفهم | أي صف ما يطابق القالب ينطبع مثل ما هو بسطر ▫️، حتى ما يضيع رقم. |
| التحديث | البوت يعيد قراءة الشيت كل 10 دقايق. للتحديث الفوري: `/refresh`. |
| الخاتمة | أرقام الفروع والهاشتاك وجملة "الأسعار ممكن تتغير" تنضاف تلقائياً بآخر كل نص. |

## التشغيل على Render

1. المستودع على GitHub بيه: `bot.py` ، `pricing.py` ، `render.py` ، `match.py` ، `requirements.txt`.
2. بـ Render: **New ← Web Service** واختار المستودع.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. المتغيرات:

| المتغير | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
| `SHEET_ID` | معرف الشيت: الجزء بين `/d/` و `/edit` بالرابط |
| `ALLOWED_CHAT_IDS` | معرف كروب الموظفين. اكتب `/id` بالكروب حتى تعرفه |

`ANTHROPIC_API_KEY` ما مطلوب بعد. إذا موجود من النسخة القديمة، يبقى أو ينحذف، ما يأثر.

**BotFather:** `/setprivacy` ← اختار البوت ← **Disable**، حتى البوت يشوف رسائل الكروب.

**الشيت:** Share ← Anyone with the link ← Viewer. المشاركة بالرابط تعني أي شخص يوصله الرابط يشوف الأسعار والعمولات. للوضع الخاص شوف تحت.

## أوامر

| الأمر | الوظيفة |
|---|---|
| `/sheets` | كل العروض الفعالة كأزرار |
| `/refresh` | إعادة قراءة الشيت هسه |
| `/id` | معرف المحادثة وهل هي مسموحة |
| `/help` | أمثلة |

## متغيرات اختيارية

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `CACHE_MINUTES` | `10` | كل كم دقيقة يعيد قراءة الشيت |
| `POST_FOOTER` | أرقام الفروع والهاشتاك | خاتمة كل نص |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | فارغ | للوضع الخاص |

## الوضع الخاص (بدون مشاركة بالرابط)

1. بـ Google Cloud Console سوي Service Account ونزّل مفتاحه بصيغة JSON.
2. شارك الشيت ويا إيميل الـ Service Account كـ Viewer، ورجّع المشاركة العامة لـ Restricted.
3. حط محتوى ملف الـ JSON كامل بمتغير `GOOGLE_SERVICE_ACCOUNT_JSON`.

## الملفات

| الملف | وظيفته |
|---|---|
| `pricing.py` | يقرأ ملف الإكسل: الشيتات الظاهرة، الخلايا المدموجة، العملة، قص العمولة |
| `render.py` | يحول الشيت إلى نص بالقالب الثابت |
| `match.py` | يطابق طلب الموظف ويا أسماء الشيتات ومحتواها |
| `bot.py` | تليكرام: الرسائل والأزرار والصلاحيات |
| `test_bot.py` | فحص بدون إنترنت: `python test_bot.py` |
